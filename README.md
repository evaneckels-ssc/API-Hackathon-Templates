# API-Hackathon-Templates
Templates and starter code to help get API Hackathon Projects off the ground

### Code Examples
- Generate Summary Reports for Full Portfolio (see full guide on [SecurityScorecard Documentation Page](https://securityscorecard.readme.io/docs/ssc-api-guide-automatically-generate-and-download-all-reports-for-a-portfolio))

### Code Templates
- Notebooks (can be used with Jupyter Notebook and Google Colab)
    - notebook_template.ipynb - Get companies in a Portfolio
    - multiple_calls_template.ipynb - Get Issue Summary for all companies in Portfolio
- Python Scripts (for use with Python environments)
    - python_template.py - Get companies in a Portfolio
